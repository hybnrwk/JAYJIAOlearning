## 二、函数定义与调用：先掌握最重要的语法骨架

### 2.1 基本语法：`def` + 参数列表 + 冒号 + 缩进

PPT 第 4 页的结构可写成：

```python
def function_name(parameter1, parameter2):
    # 函数体：必须缩进
    result = parameter1 + parameter2
    return result
```

逐个理解：

| 语法部分 | 含义 | 易错点 |
|---|---|---|
| `def` | 定义函数的关键字 | 不能省略 |
| `function_name` | 函数名，遵守变量命名规则 | 不能用关键字作函数名 |
| `(...)` | 形参列表，可以为空 | 定义和调用都要写圆括号 |
| `,` | 分隔多个参数 | 不能用分号替代 |
| `:` | 开始函数代码块 | **必须有冒号** |
| 四空格缩进 | 确定哪些代码属于函数体 | **缩进是语法的一部分** |
| `return` | 结束本次函数调用，可返回结果 | 可以不写，但不会自动返回最后一个表达式 |

一个最简单的完整程序（对应 PPT 第 6 页）：

```python
def add(num1, num2):
    total = num1 + num2
    return total

answer = add(10, 20)
print(answer)  # 30
```

注意 `answer = add(10, 20)` **没有缩进**，因此它在函数外部执行。PPT 用 `sum` 作为变量名，这在语法上可行，但会遮蔽 Python 内置的 `sum()` 函数；实际建议使用 `total` 或 `answer`。

Python 与 C++ 的关键差异：

```cpp
// C++
int add(int a, int b) {
    return a + b;
}
```

```python
# Python
def add(a, b):
    return a + b
```

- **不需要在函数名前声明返回类型，也不需要在参数前写 `int`。**
- **不用大括号 `{}` 界定代码块，也通常不用分号 `;`。**
- 缩进一般为四个空格；函数定义行末的 `:` 不能遗漏。

### 2.2 没有参数、没有显式返回值也可以

```python
def say_hello():
    print("Hello")

say_hello()
```

注意空括号 `()` 不能省：

```python
say_hello    # 引用函数对象；这里没有调用
say_hello()  # 执行函数
```

如果暂时还没有实现函数，可以用 `pass` 作为占位语句：

```python
def future_task():
    pass
```

如果冒号后面什么也不写，就会得到 `IndentationError`（要求缩进的代码块）。

### 2.3 `def` 只定义函数，调用时才执行函数体

```python
def test():
    print("函数正在执行")

print("A")
test()
print("B")
```

输出：

```text
A
函数正在执行
B
```

**执行顺序**：运行 `def test(): ...` 时创建函数，调用 `test()` 才执行其中的 `print`。这对应 PPT 第 8 页的函数调用流程：调用处暂停 → 绑定参数 → 执行函数体 → 返回调用处继续执行。

**调用前，函数名必须已经通过执行 `def` 绑定好**：

```python
# 这种顺序是正确的
def greet():
    print("Hi")

greet()
```

若在脚本顶层先写 `greet()`，随后才运行到 `def greet(): ...`，通常会得到 `NameError`。不过，在一个已定义函数的内部引用稍后才定义的另一个函数，只要真正调用前后者已定义，也可以正常运行。

### 2.4 形参与实参（Parameters / Arguments）

```python
def add(a, b):     # a、b 是形参
    return a + b

add(10, 20)        # 10、20 是实参
```

- **形参**：函数定义中接收数据的变量名。
- **实参**：调用时实际提供的值或表达式。
- 调用时会先求出实参表达式的值，再让形参绑定到对应对象。

**重要修正（对应 PPT 第 8 页）**：课件用“实参复制给形参”帮助解释调用流程，但 Python 并不会因此把列表、字典等对象自动深拷贝。更准确的说法是：**参数名绑定到传入的对象**。这一点在下面的“可变对象”部分很重要。

### 2.5 好函数的设计原则

PPT 第 7 页强调代码复用、功能单一、高内聚、低耦合。落实到写代码，就是：

```python
def calculate_area(radius):
    return 3.14159 * radius ** 2

radius = 10
area = calculate_area(radius)
print(area)
```

函数专注“计算面积”，调用者负责“输入什么半径”和“如何展示结果”。尽量避免计算函数内部到处 `input()`，也不要依赖无关的全局变量。

## 三、函数参数：本章最容易写错的语法

**参数负责把信息从函数外部传到内部**。下面所有参数形式都围绕同一个问题：调用时应该把值交给哪个形参？（PPT 第 12—19 页）

### 3.1 位置参数（Positional Arguments）

```python
def subtract(a, b):
    return a - b

print(subtract(10, 3))  # 7
print(subtract(3, 10))  # -7
```

位置参数按**顺序**匹配：第一个传 `a`，第二个传 `b`。不能随便交换。

普通情况下，缺少参数或传入过多参数会抛出 `TypeError`：

```text
subtract(10)       # 缺少 b
subtract(10, 3, 2) # 多传了一个参数
```

### 3.2 关键字参数（Keyword Arguments）

```python
def location(x, y=20, z=30):
    print("x =", x, "; y =", y, "; z =", z)

location(50, 60, 70)  # x=50, y=60, z=70
location(z=100, x=80) # x=80, y=20, z=100
```

这是 PPT 第 14 页的例子。关键字参数写成 `形参名=值`，**可以改变提供实参的顺序**：

```python
location(x=80, z=100)
```

特别注意：形参的名字要写对，传 `q=100` 会因为函数没有 `q` 参数而得到 `TypeError`（除非函数使用 `**kwargs` 接收）。

### 3.3 默认参数（Default Arguments）

```python
def person(name, nationality="中国"):
    print(f"姓名：{name}，国籍：{nationality}")

person("小明")           # 使用默认值“中国”
person("Tom", "USA")    # 用实参覆盖默认值
```

这是 PPT 第 13 页例子的可运行写法。

**定义时，一般要求没有默认值的参数在普通参数列表中出现在有默认值的参数之前。**

```python
# 正确
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")
```

以下定义会导致 `SyntaxError`：

```text
def greet(greeting="Hello", name):
    ...
```

原因：非默认的普通参数 `name` 出现在默认参数之后。（现代 Python 对专门的仅关键字参数等有更灵活的规则；本章初学先按上述常见形式掌握即可。）

### 3.4 位置参数和关键字参数混用

```python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice", greeting="Hi")  # Hi, Alice!
```

PPT 第 15 页的核心要求是：**调用时，一般将位置参数放在关键字参数之前。**

不能这样写：

```text
greet(name="Alice", "Hi")  # SyntaxError
```

也不能把同一形参赋值两次：

```text
greet("Alice", name="Bob") # TypeError：name 收到了两个值
```

所以写较复杂的调用时，建议采用：

```python
function_name(必需位置参数, 参数名1=值1, 参数名2=值2)
```

上面最后一行只是调用形式的说明；实际运行时要换成已经定义的函数名和真实变量。

### 3.5 **最重要的陷阱**：列表/字典不要直接做默认值

PPT 第 16 页的代码：

```python
def append_to_list(value, my_list=[]):
    my_list.append(value)
    return my_list

print(append_to_list(1))  # [1]
print(append_to_list(2))  # [1, 2]，并不是 [2]
```

为什么？**默认值在执行 `def` 时创建一次，后面省略该参数的调用会复用同一个列表。** 第二次调用不是创建新空列表，而是在旧列表 `[1]` 后加上 `2`。

**需要纠正 PPT 第 13 页的一句话**：默认参数值并非“语法上必须是不可变对象”。`[]` 和 `{}` 作默认值在语法上合法，只是大多数时候会导致不符合预期的共享状态。因此推荐使用 `None`：

```python
def append_to_list(value, my_list=None):
    if my_list is None:
        my_list = []
    my_list.append(value)
    return my_list

print(append_to_list(1))  # [1]
print(append_to_list(2))  # [2]
```

这正是 PPT 第 17 页推荐的解决办法。

进一步理解：

```python
existing = [10]
result = append_to_list(20, existing)
print(existing)  # [10, 20]
print(result)    # [10, 20]
```

显式传入已有列表时，函数内部的 `.append()` **会修改传入的列表对象**。`None` 的方案只避免“不同次省略参数的调用共享一个默认列表”，并不自动复制你主动传进来的列表。

### 3.6 `*args`：接收任意数量的位置参数

```python
def sum_all(*args):
    print(args)
    return sum(args)

print(sum_all(1, 2, 3))
```

输出：

```text
(1, 2, 3)
6
```

读法：

- `*args` 出现在**定义函数**时，将多余的位置实参收集为一个 `tuple`（元组）。
- `args` 只是习惯命名，换成 `*numbers` 也合法；真正特殊的是前面的 `*`。
- 没有附加位置实参时得到空元组 `()`。

```python
def show_numbers(first, *others):
    print("第一个：", first)
    print("其余：", others)

show_numbers(10, 20, 30)
# 第一个：10
# 其余：(20, 30)
```

### 3.7 `**kwargs`：接收任意数量的关键字参数

```python
def show_profile(**kwargs):
    print(kwargs)

show_profile(name="Alice", age=20)
# {'name': 'Alice', 'age': 20}
```

`**kwargs` 把多余的关键字参数收集成 `dict`（字典），`kwargs` 也只是惯用名称。

记忆：

| 写法（定义函数时） | 接收什么 | 函数体里是什么类型 |
|---|---|---|
| `*args` | 多余的位置实参 | `tuple` |
| `**kwargs` | 多余的关键字实参 | `dict` |

### 3.8 `*args` 和 `**kwargs` 联用：酒店案例

PPT 第 19 页：

```python
def reserve_hotel(name, *room_numbers, **amenities):
    print("Hotel name:", name)

    for room_number in room_numbers:
        print("Room number:", room_number)

    for amenity, quantity in amenities.items():
        print(f"{amenity}: {quantity}")

reserve_hotel("Hotel A", 101, 102, beds=2, TV=1)
```

把这一行拆开：

```python
reserve_hotel("Hotel A", 101, 102, beds=2, TV=1)
```

- `name = "Hotel A"`；
- `room_numbers = (101, 102)`；
- `amenities = {"beds": 2, "TV": 1}`。

因此，**`def f(a, *args, **kwargs):` 是这一节最值得记住的完整模板**。各部分能省略，但 `**kwargs` 通常放在最后。

### 3.9 容易混淆：定义处的 `*` 与调用处的 `*`

这是对 PPT 的实用补充：同一个符号在两个位置有不同用途。

```python
def add_three(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
print(add_three(*numbers))  # 6
```

在**调用**时，`*numbers` 是将序列**拆开为多个位置实参**；而在定义时，`*args` 是**收集位置实参**。

```python
def introduce(name, age):
    print(name, age)

data = {"name": "Tom", "age": 20}
introduce(**data)
```

调用处的 `**data` 将字典键值对拆为关键字实参。不要把“收集参数”和“展开参数”混为一谈。

### 3.10 扩展：了解一次 `*` 的另一种用法即可

下面不是 PPT 的考试主线，但阅读现代 Python 代码常见：

```python
def connect(host, *, timeout=10):
    print(host, timeout)

connect("localhost", timeout=5)  # 正确
```

单独的 `*` 表示其后的参数是**仅关键字参数（keyword-only）**。因此 `connect("localhost", 5)` 会得到 `TypeError`。这和 `*args` 的含义不同。

## 四、变量作用域：函数内外为什么有时找不到变量

PPT 第 9—11 页把变量分为局部变量（Local Variables）和全局变量（Global Variables）。

### 4.1 局部变量：函数外部通常不能直接访问

```python
def calculate(x):
    result = x * 2
    return result

print(calculate(5))  # 10
# print(result)     # NameError：这里没有定义全局 result
```

`result` 是函数内部的局部变量。函数的返回值可以交给外面的一个新变量：

```python
answer = calculate(5)
print(answer)
```

**重点**：Python 中 `if`、`for`、`while` 通常不会像 C++ 的 `{}` 那样引入新的局部作用域；而函数会形成自己的局部命名空间。

### 4.2 读取全局变量：通常不需要 `global`

PPT 第 11 页的圆面积例子：

```python
PI = 3.14

def circle_area(radius):
    area = PI * radius ** 2
    return area

print(circle_area(10))  # 314.0
```

`PI` 在函数外定义；函数体只是**读取** `PI`，不需要 `global`。

### 4.3 修改全局变量的绑定：用 `global`

```python
count = 0

def increase():
    global count
    count += 1

increase()
increase()
print(count)  # 2
```

这里 `global count` 表示函数内部的 `count` 指向模块级变量，而不是局部变量。

没有 `global` 时：

```text
count = 0

def increase():
    count += 1  # 常见错误：UnboundLocalError
```

原因不是 `+=` 语法有错，而是 Python 在这个函数中把 `count` 视为局部变量；它尚未获得值就被读取。

PPT 使用：

```python
PI = 3.14
area = 0

def circle_area(radius):
    global area
    area = PI * radius ** 2
    return area
```

这是合法的；不过更推荐直接返回面积，让调用者决定如何保存结果，减少函数之间的隐式依赖。

### 4.4 更精确地理解：修改对象与重新赋值不是一回事

```python
records = []

def add_record(x):
    records.append(x)  # 修改共享列表的内容；此处不需要 global

add_record(10)
print(records)  # [10]
```

但如果在函数中写：

```text
records = []

def reset():
    records = []  # 创建并绑定一个新的局部变量，不会重置外部的 records
```

就不等于修改了外部列表。

你需要记住的精确规则是：**`global` 用来声明名称的全局绑定，不是访问全局对象时的必备语法。**

### 4.5 `nonlocal`：作为补充认识

```python
def outer():
    value = 0

    def inner():
        nonlocal value
        value += 1

    inner()
    return value

print(outer())  # 1
```

`nonlocal` 修改外围函数作用域中的名称，而不是模块级全局变量。PPT 未将其作为本章重点，只需知道它与 `global` 的区别。

## 五、返回值：必须分清 `return` 和 `print`

PPT 第 20—21 页的中心思想是：**参数负责传入信息；返回值负责把计算结果传回调用者。**

### 5.1 无显式返回值：实际返回 `None`

```python
def print_hello(name):
    print("Welcome", name)

result = print_hello("小明")
print(result)
```

输出：

```text
Welcome 小明
None
```

`print()` 把内容显示到屏幕上，不等于把计算结果返回给调用者。函数没有显式 `return` 时，隐含返回 `None`。

### 5.2 返回一个值

```python
def square(x):
    return x ** 2

result = square(5)
print(result)  # 25
```

`return` 做两件事：

1. 结束**本次函数调用**；
2. 将表达式的结果交还给调用者。

例如：

```python
def check_score(score):
    if score < 0 or score > 100:
        return "无效成绩"
    return "有效成绩"
```

如果满足第一个 `return`，第二个 `return` 就不会执行。

### 5.3 `return` 立即退出函数，而不只是退出 `if` 或循环

```python
def find_first_even(numbers):
    for number in numbers:
        if number % 2 == 0:
            return number
    return None

print(find_first_even([1, 3, 6, 8]))  # 6
```

一旦找到 `6`，本次函数就结束，后面的 `8` 不再扫描。

与之区分：

- `break`：退出**当前循环**，函数中的后续代码仍可执行；
- `continue`：跳到循环的下一轮；
- `return`：直接退出**当前函数**。

### 5.4 返回多个值：实际上返回一个元组

PPT 第 21 页演示交换两个值。用容易辨认的函数名改写：

```python
def swap(first, second):
    return second, first

result = swap("a", "b")
print(result)        # ('b', 'a')
print(type(result))  # <class 'tuple'>
```

最常用的是直接**解包（unpacking）**：

```python
x, y = swap("a", "b")
print(x)  # b
print(y)  # a
```

注意：这里并不是存在两个互不相干的 `return`，而是 `return second, first` 构成一个元组。调用方的接收变量数量应当匹配解包项数，否则可能出现 `ValueError`。

多个结果较多时，PPT 建议使用字典、命名元组或类使各字段含义清晰。基础作业常用的两三个返回值直接使用元组即可。

### 5.5 完整程序常见写法：`main()`

PPT 第 32 页练习要求“在 `main()` 中调用四个函数”。示范骨架如下：

```python
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    return a / b


def main():
    x, y = 10, 2
    print(add(x, y))
    print(subtract(x, y))
    print(multiply(x, y))
    print(divide(x, y))


if __name__ == "__main__":
    main()
```

- `main` **不是 Python 保留的特殊函数名**，是程序员自己约定的入口函数。
- `if __name__ == "__main__":` 是常见脚本入口保护：直接运行文件时执行 `main()`；作为模块导入时不自动运行这段入口代码。
- 如果除数可能是零，`divide` 需要事先检查 `b == 0`，否则会有 `ZeroDivisionError`。本例仅演示函数定义与调用语法。

## 六、Lambda：只有一个表达式的简短函数

PPT 第 22 页：

```python
f = lambda x, y, z: x + y + z
print(f(1, 2, 3))  # 6
```

一般形式：

```text
lambda 参数1, 参数2, ...: 表达式
```

等价于：

```python
def f(x, y, z):
    return x + y + z
```

但要牢记：

- `lambda` 本身会创建一个函数对象，可以赋给变量，也可以直接传给另一个函数；
- `lambda` 后面只允许一个**表达式（expression）**，不能在里面直接写多个普通语句、`for` 循环语句或 `return` 语句；
- 传入参数时的规则和普通函数一致；
- 功能一旦复杂，优先使用 `def`。

**错误**（不能把 `return` 放进 lambda）：

```text
f = lambda x: return x + 1
```

**正确**：

```python
f = lambda x: x + 1
```

Lambda 适合**作为函数的参数**，例如排序（对 PPT 的小幅实用拓展）：

```python
students = [("Alice", 95), ("Bob", 88), ("Carol", 92)]

# 按每个元组的第 2 个元素（成绩）降序排列
result = sorted(students, key=lambda item: item[1], reverse=True)
print(result)
```

一句话：`lambda item: item[1]` 定义了一个简单的“从记录中抽取排序依据”的函数。

**多条件也能写成表达式**：

```python
level = lambda score: "pass" if score >= 60 else "fail"
print(level(80))  # pass
```

注意表达式形式是 `A if 条件 else B`，不是 `if 条件: ... else: ...` 这样的语句块。

## 七、文档字符串：写在函数体第一条语句的位置

PPT 第 23 页讲解 **Docstring（Documentation String）**：

```python
def area_of_circle(radius):
    """计算给定半径的圆面积，并返回数值结果。"""
    return 3.14159 * radius ** 2

print(area_of_circle(2))
print(area_of_circle.__doc__)
```

语法要点：

1. 使用三引号 `"""..."""` 或 `'''...'''`。
2. 放在函数体中的**第一个语句**位置时，这个字符串成为函数的文档字符串。
3. 用 `函数名.__doc__` 读取，`doc` 左右各有**两个下划线**。
4. `help(函数名)` 也可查看函数文档。

更完整的写法：

```python
def divide(a, b):
    """计算 a / b。

    参数:
        a: 被除数
        b: 除数，不应为零
    返回:
        a / b 的结果
    """
    return a / b
```

它和 `# 注释` 的区别：注释通常用于解释局部代码；文档字符串可通过 `__doc__` 被程序或工具提取。

**另一个 PPT 易忽视之处**：第 23 页使用 `def max(a, b)` 作为例子，这会遮蔽 Python 自带的 `max()`。推荐改名为 `max_of_two`，避免影响后续代码。

## 八、字符串处理方法：本章 PPT 也要求掌握

PPT 第 24—25 页在函数章节中专门介绍 `str` 的常用方法。虽然严格来说它们是**字符串对象的方法（Methods）**，但调用语法也属于函数使用的一部分。

### 8.1 方法调用和普通函数调用的写法差异

```python
text = "hello world"
print(text.upper())  # HELLO WORLD
```

这里：

- `text`：字符串对象；
- `.upper`：访问该对象的方法；
- `()`：**调用**该方法。

`text.upper` 和 `text.upper()` 并不相同，后者才会产生转换后的字符串。

### 8.2 PPT 的全部常用字符串方法

| 方法 | 功能 | 示例与结果 |
|---|---|---|
| `format()` | 格式化字符串 | `"{}".format(42)` → `"42"` |
| `join()` | 用分隔符拼接多个字符串 | `"-".join(["a", "b"])` → `"a-b"` |
| `split()` | 根据分隔规则拆分为列表 | `"a b".split()` → `["a", "b"]` |
| `replace()` | 替换匹配的子串 | `"bat".replace("b", "c")` → `"cat"` |
| `strip()` | 去掉字符串两端的空白或指定字符 | `" hi ".strip()` → `"hi"` |
| `upper()` | 转大写 | `"hi".upper()` → `"HI"` |
| `lower()` | 转小写 | `"HI".lower()` → `"hi"` |
| `capitalize()` | 首字符大写，其余变小写 | `"hELLO".capitalize()` → `"Hello"` |
| `title()` | 每个词的首字母大写（近似理解） | `"hello world".title()` → `"Hello World"` |
| `find()` | 返回首次出现的位置，未找到返回 `-1` | `"hello".find("ll")` → `2` |
| `startswith()` | 检查前缀，返回布尔值 | `"report.pdf".startswith("re")` → `True` |
| `endswith()` | 检查后缀，返回布尔值 | `"report.pdf".endswith(".pdf")` → `True` |

**用法 1：`join()` 的调用方向容易写反**

```python
words = ["Hello", "World"]
sentence = " ".join(words)
print(sentence)  # Hello World
```

它的结构是：

```text
"分隔符".join(字符串序列)
```

不是 `words.join(" ")`；而且参与拼接的元素必须是字符串，数字列表不能直接传给 `join`。

**用法 2：`split()` 的有参/无参行为不同**

```python
print("a   b".split())    # ['a', 'b']
print("a   b".split(" ")) # ['a', '', '', 'b']
```

PPT 将无参形式解释为“默认按空格分隔”，更准确地说它会按**连续空白字符**（空格、制表符、换行等）分隔，自动忽略首尾多余空白；显式传入 `" "` 时会将每个单独空格当分隔符。

**用法 3：`strip()` 只处理两端，不清理中间**

```python
print("  hello world  ".strip())  # hello world
print("a-b-c".replace("-", " "))  # a b c
```

**用法 4：`find()` 和 `in`**

```python
text = "hello world"
print(text.find("world"))  # 6
print(text.find("python")) # -1
print("world" in text)     # True
```

若只需判断子串是否存在，`"world" in text` 通常更直观；如果还要位置，用 `find()`。

### 8.3 字符串是不可变的：方法一般返回新字符串

```python
text = "hello"
text.upper()
print(text)  # hello，原值没有变化

text = text.upper()
print(text)  # HELLO
```

别以为调用 `upper()`、`replace()`、`strip()` 就原地修改了原字符串。

```python
s = "madam"

```

基本格式：`s[start:stop:step]`。其中 `[::-1]` 表示倒序遍历。可以用于 PPT 第 32 页的回文题：

def is_palindrome(s):

print(is_palindrome("madam"))  # True

## 九、递归：函数在内部调用自己

PPT 第 26—28 页以阶乘说明递归（Recursion），并比较递归和循环。

### 9.1 递归的三个条件

编写递归时，必须回答：

1. **子问题是什么**：原问题如何转成同一类、更小的子问题？
2. **终止条件（Base Case）是什么**：什么时候不再往下调用？
3. **如何组合子问题的答案**：从较小问题得到原问题结果？

例如阶乘：

$$
0! = 1, \qquad n! = n\,(n-1)! \quad (n\ge 1).
$$

注意：课件第 27 页的数学关系在文本提取中容易显示成 `n! = n(n-1)`；正确的递推应当有 `(n-1)!`。

### 9.2 用 `factorial` 写阶乘

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(3))  # 6
```

展开过程：

```text
factorial(3)
= 3 * factorial(2)
= 3 * (2 * factorial(1))
= 3 * (2 * (1 * factorial(0)))
= 3 * (2 * (1 * 1))
= 6
```

从运行机制看，它是**先不断进入新的函数调用，再从最深层逐层返回**。不是简单地将所有语句执行一遍。

### 9.3 对照 PPT 的打印跟踪版本

```python
def factorial(n):
    print(f"calling factorial({n})")

    if n == 0:
        print("factorial(0) returns 1")
        return 1
    else:
        value = n * factorial(n - 1)
        print(f"factorial({n}) returns {value}")
        return value

fact = factorial(3)
print(f"Result: factorial(3) = {fact}")
```

观察输出，你会看到 `calling factorial(3)`、`calling factorial(2)`……先发生，`returns` 从 0 逐级向 3 返回。这是**函数调用栈（Call Stack）**的直观体现。

### 9.4 两个常见错误

**错误一：没有终止条件**，或参数并未逐渐靠近终止条件：

```text
def f(n):
    return f(n)
```

这段代码持续调用自身，Python 会在达到递归深度限制时抛出 `RecursionError`，并不是无限制地一直运行。

**错误二：未处理不合适的输入**。上面的最简 `factorial` 只适用于非负整数。如果传 `-1`，`n` 会越来越小，永远到不了 `0`。

可用更稳妥的实现：

```python
def factorial(n):
    if not isinstance(n, int) or isinstance(n, bool) or n < 0:
        raise ValueError("n 必须是非负整数")
    if n == 0:
        return 1
    return n * factorial(n - 1)
```

### 9.5 递归 vs 循环：怎么选

同一阶乘问题也可用循环：

```python
def factorial_iterative(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial_iterative(3))  # 6
```

| 方面 | 递归 | 循环 |
|---|---|---|
| 重复方式 | 不断调用自身 | 重复执行循环体 |
| 必需条件 | 递归终止条件 | 循环退出条件 |
| 主要风险 | 递归深度限制、重复计算 | 死循环、状态更新错误 |
| 适用直觉 | 树结构、分治、可自然分解的子问题 | 简单计数、线性迭代 |

PPT 第 28 页的建议是：如果两种实现的复杂程度相近，**优先考虑循环**。在 Python 中，这样也能避免不必要的递归调用开销。

## 十、课件应用案例：用真实代码巩固函数语法

### 10.1 案例一：等额本息还款（PPT 第 29 页）

任务：把贷款本金、年利率和贷款年数作为参数，返回每月应还款金额。

设贷款本金为 $P$，年利率为 $r_a$，每月利率 $r=r_a/12$，贷款年数为 $Y$，总期数 $n=12Y$，则：

$$
M=\frac{P\,r\,(1+r)^n}{(1+r)^n-1}.
$$

**PPT 代码中的一个排版陷阱**：把除号 `/` 放在物理行末后直接换行，如果外部没有一层尚未闭合的括号，会导致语法错误。应使用**外层括号包住整个表达式**。以下可以直接运行：

```python
def calculate_monthly_payment(principal, annual_interest_rate, loan_years):
    number_of_payments = loan_years * 12
    monthly_interest_rate = annual_interest_rate / 12

    if monthly_interest_rate == 0:
        return principal / number_of_payments

    monthly_payment = (
        principal
        * monthly_interest_rate
        * (1 + monthly_interest_rate) ** number_of_payments
        / ((1 + monthly_interest_rate) ** number_of_payments - 1)
    )
    return monthly_payment

principal = 100000
annual_interest_rate = 0.05
loan_years = 10

payment = calculate_monthly_payment(principal, annual_interest_rate, loan_years)
print(f"贷款 {principal} 元，年利率 {annual_interest_rate:.0%}，月供 {payment:.2f} 元")
```

这一案例覆盖：

- `def calculate_monthly_payment(principal, annual_interest_rate, loan_years):` —— 三个形参；
- `**` —— 乘方，而不是 `^`；
- 分行表达式 —— 在括号内可安全换行；
- `return monthly_payment` —— 返回值；
- `f"...{payment:.2f}..."` —— 格式化为两位小数；
- `if monthly_interest_rate == 0` —— 处理零利率，避免分母为零。

这里假定贷款年数为正值且输入合理；生产级程序还应检查本金、利率和期限是否合法，但这不是本 PPT 的语法重点。

**另一个细节**：PPT 中跨行展示的 `print(f"...")`，实际写入 `.py` 文件时如果直接在单行引号内敲回车，也可能形成未结束的字符串。推荐保持在一行，或使用括号内相邻字符串自动拼接。

### 10.2 案例二：股票期望回报率（PPT 第 30 页）

PPT 使用类似 CAPM 的关系：

$$
E[R] = R_f + \beta (R_m-R_f).
$$

```python
def expected_return(risk_free_rate, beta, market_return):
    return risk_free_rate + beta * (market_return - risk_free_rate)

expected_r = expected_return(0.03, 1.2, 0.08)
print(f"期望回报率为：{expected_r * 100:.2f}%")  # 9.00%
```

也可以改成 PPT 提到的 Lambda：

```python
expected_return = lambda risk_free_rate, beta, market_return: (
    risk_free_rate + beta * (market_return - risk_free_rate)
)

expected_r = expected_return(0.03, 1.2, 0.08)
print(f"期望回报率为：{expected_r * 100:.2f}%")
```

这段 `lambda` 如果要换行，**要将表达式放在括号中**；直接在 `+` 之后换行且没有有效的括号包裹，会产生语法错误。PPT 的公式展示和跨行代码不能不加检查地原样复制。

注意本案例讲的是**使用 Beta 估计期望回报率**；没有单独计算风险方差或波动率，不应误认为输出了一个独立的风险数值。

### 11.1 题 2：`*args` 的标准写法

```python
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3, 4))  # 10
print(sum_all())           # 0
```

**辨认**：参数名 `args` 在函数体里是 `tuple`，而 Python 内置的 `sum()` 可以计算其中数值的和。

### 11.2 题 4：函数相互调用与多个结果

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return abs(a)


def lcm(a, b):
    if a == 0 or b == 0:
        return 0
    return abs(a * b) // gcd(a, b)

print(gcd(12, 18))  # 6
print(lcm(12, 18))  # 36
```

观察这里：`lcm()` 内部调用 `gcd()`，是函数的组合；`a, b = b, a % b` 是 Python 多变量同时赋值，避免临时变量。

### 11.3 题 6：Lambda 如何表示分段函数

对于 PPT 的奖金计算条件，先写成**普通函数**最容易保证逻辑正确：

```python
def bonus(profit):
    if profit <= 100000:
        return profit * 0.10
    elif profit <= 200000:
        return 100000 * 0.10 + (profit - 100000) * 0.20
    else:
        return 100000 * 0.10 + 100000 * 0.20 + (profit - 200000) * 0.30
```

如果题目指定 Lambda，需要改成**条件表达式**，不能照抄 `if:` 语句块：

```python
bonus_lambda = lambda profit: (
    profit * 0.10
    if profit <= 100000
    else 10000 + (profit - 100000) * 0.20
    if profit <= 200000
    else 30000 + (profit - 200000) * 0.30
)

print(bonus_lambda(250000))  # 45000.0
```

这里的连续 `if ... else ...` 是条件表达式的嵌套，不是两个 `elif`。若实际题目要求考虑负利润、上限或其他边界，应另行添加。

### 11.4 题 7：税率表的读取方式

### 11.5 题 8：把大任务拆成三个函数

这道题最重要的不是数学证明，而是函数的职责分工：

```python
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True


def goldbach(n):
    for p in range(2, n):
        if is_prime(p) and is_prime(n - p):
            return p, n - p
    return None


def main():
    for n in range(6, 1001, 2):
        result = goldbach(n)
        if result is None:
            print(f"{n} 未找到符合条件的质数对")
            return
    print("6～1000 之间的所有偶数均满足哥德巴赫猜想")


if __name__ == "__main__":
    main()
```

这里 `is_prime()` 负责“判断”，`goldbach()` 负责“寻找”，`main()` 负责“批量验证并汇报结果”。课件要求 `goldbach()` 输出质数对，上面的写法为了让函数更容易复用，选择**返回质数对**，若需严格按照题目形式逐对打印，可以在 `goldbach()` 找到结果时或 `main()` 中增加 `print`。

## 十二、Python 函数语法防错清单（写作业前快速核查）

### 12.1 常见错误按类别分清

| 常见写法或现象 | 错误类型 | 正确思路 |
|---|---|---|
| `def f(x)` 忘记 `:` | `SyntaxError` | `def f(x):` |
| `def f(x):` 之后的函数体没缩进 | `IndentationError` | 函数体统一缩进 4 空格 |
| 使用 `return`，但位置不在函数体内 | `SyntaxError` | 把 `return` 放在 `def` 内 |
| `def f(a=1, b):` | `SyntaxError` | 常见写法改为 `def f(b, a=1):` |
| `f(a=1, 2)` | `SyntaxError` | 先位置实参再关键字实参 |
| 在 lambda 中写 `return` 语句 | `SyntaxError` | `lambda x: x + 1` |
| 拷贝 PPT 时在 `/` 或 `+` 后直接换行 | 可能 `SyntaxError` | 使用外层括号包住多行表达式 |
| 不规范的中文弯引号 `‘ ’ “ ”` 作为代码引号 | 常见 `SyntaxError` | 在 Python 代码中使用 `'` 或 `"` |
| 传参数少了/多了/名称不匹配 | `TypeError` | 核对函数签名和调用实参 |
| 同一参数既按位置又按名称传值 | `TypeError` | 每个参数只传一次 |
| 函数内部 `count += 1`，但 `count` 本应为全局变量 | `UnboundLocalError` | `global count` 或改为参数+返回值 |
| 对没有定义的函数名进行调用 | `NameError` | 确保调用时该名称已定义 |
| `x = print(...)` 后拿 `x` 做加法 | `TypeError` | 需要结果时让函数 `return` 数字 |
| `factorial(-1)` 且只在 `n == 0` 时停止 | `RecursionError` | 验证输入、明确终止条件 |
| 在不同调用间复用 `my_list=[]` 默认值 | 通常**不报语法错**，但逻辑容易错 | 改为 `my_list=None` 并在函数内创建列表 |

### 12.2 每次写新函数，按这个顺序检查

1. **定义**：有没有 `def`、英文圆括号 `()`、英文冒号 `:`、正确缩进？
2. **形参**：数量、名称、默认值位置和 `*args/**kwargs` 的收集范围是否正确？
3. **调用**：调用之前是否定义了函数？位置参数和关键字参数是否重复或混放？
4. **变量**：函数体中每个局部变量使用前是否赋值？是否误把全局变量当局部变量？
5. **返回**：需要结果就用 `return`；不用时确认 `None` 是否符合预期；是否误以为 `print` 会返回打印内容？
6. **可变对象**：列表、字典参数有没有意外修改调用者对象？是否用了可变默认值？
7. **递归/循环**：是否能够退出？递归参数是否真正向终止条件接近？
8. **字符串/分行**：引号是否配对？长表达式是否在括号内换行？

### 12.3 最后记住这 12 行语法模板

```python
# 1. 定义普通函数
def add(a, b):
    return a + b

# 2. 默认参数 + 关键字调用
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}"

print(greet("Alice", greeting="Hi"))

# 3. 任意位置参数和关键字参数
def collect(*args, **kwargs):
    return args, kwargs

# 4. 无返回值函数（隐含返回 None）
def show(x):
    print(x)

# 5. 多个返回值（元组）
def swap(a, b):
    return b, a

# 6. 简单 Lambda
square = lambda x: x ** 2

# 7. 递归
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
```

> **本章总结**：函数的核心语法是 `def → 参数绑定 → 函数体 → return → 调用处继续执行`。与其他语言相比，最需要特别练熟的是**冒号和缩进、参数规则、`return` 与 `print` 的区别、局部/全局名称绑定、默认可变对象陷阱、`*args/**kwargs` 的收集和展开，以及 Lambda 只能写表达式**。这些掌握后，就可以比较稳当地完成 PPT 中的函数类编程作业。
