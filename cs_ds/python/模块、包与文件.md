# **第一部分：第六章 模块与包（Modules and Packages）**

## **二、为什么需要模块？**

先想一个问题：

如果我们写一个程序，只有几十行代码，直接全部写在一个 `.py` 文件中就可以。

但如果程序有几千行代码呢？

例如，一个学生管理系统可能包含：

- 学生信息管理；
    
- 成绩统计；
    
- 课程管理；
    
- 数据读取；
    
- 数据保存；
    
- 用户交互。
    

如果全部写在一个文件中，代码会越来越难以维护。

因此，Python 引入了模块（Module）和包（Package）。

PPT 第 3–6 页的核心思想就是软件工程中的一个原则：**分而治之（Divide and Conquer）**。

将一个大的程序拆分成多个功能相对独立的小部分，每部分负责自己的任务。

模块和包.pdf

### **1. 函数、模块、包之间的关系**

这三个概念可以理解为三个不同层次：

**函数（Function）**

完成一个具体任务，例如计算平均分。

`def average(scores): ...`

**模块（Module）**

将相关函数、类和变量组织到一个 Python 文件中。

`statistics.py`

**包（Package）**

将多个相关模块组织到一个目录中。

`student_management/`

例如：

- 一个函数可以计算学生平均成绩。
    
- 一个模块可以包含平均分、最高分、最低分等统计函数。
    
- 一个包可以包含学生管理、成绩统计、课程管理等多个模块。
    

注意：模块不是函数的另一种写法，而是一个独立的代码文件。

## **三、模块 Module**

### **1. 什么是模块？**

Python 中，一个 `.py` 文件就可以作为一个模块。

例如，我们创建一个名为 `math_operations.py` 的文件：

```

# math_operations.py

def add(x, y):
    return x + y


def subtract(x, y):
    return x - y


def multiply(x, y):
    return x * y


def divide(x, y):
    return x / y
```

这个文件就是一个模块，里面定义了四个函数。

现在，我们再创建一个文件 `main.py`：

```

# main.py

import math_operations

result = math_operations.add(10, 5)

print(result)
```

输出：

```
15
```

这里最重要的语法是：

```
import math_operations
```

意思是导入 `math_operations.py` 这个模块。

然后：

```
math_operations.add(10, 5)
```

表示调用模块里面的 `add()` 函数。

可以理解为：

\[ \text{模块名.函数名()} \]

这和 C++ 中通过头文件声明并使用其他文件中的函数有相似之处，但 Python 的模块导入机制并不等同于 C++ 的 `#include`。

### **2. 两种主要的模块导入方式（重点）**

PPT 第 7–8 页介绍了两种方式。

**方式一：导入整个模块**

```
import math

print(math.sqrt(16))
print(math.pow(2, 3))
```

这里导入了整个 `math` 模块。

调用时必须使用：

```
模块名.函数名()
```

优点是结构清楚，能看出函数来自哪个模块，也不容易产生名称冲突。

还可以给模块起别名：

```
import numpy as np

a = np.array([1, 2, 3])
```

这里 `np` 就是 `numpy` 的别名。

你以后学习数据科学会经常见到：

```
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

这几个都是非常常见的写法。

**方式二：只导入模块中的某个对象**

```
from math import sqrt

print(sqrt(16))
```

这里直接导入了 `sqrt`，因此不需要再写 `math.sqrt()`。

也可以导入多个对象：

```
from math import sqrt, pow
```

或者使用别名：

```
from math import sqrt as square_root

print(square_root(16))
```

两种方式的比较：

|对比|`import math`|`from math import sqrt`|
|---|---|---|
|导入方式|导入模块|导入指定对象|
|调用|`math.sqrt()`|`sqrt()`|
|命名空间|保留模块前缀|直接使用函数名|
|可读性|来源明确|调用简洁|

我更建议你平时优先使用 `import 模块名`，或者明确指定需要导入的对象。

不建议大量使用：

```
from math import *
```

因为这样会把大量名称直接引入当前文件，容易发生命名冲突，也不容易看出函数的来源。

另外，PPT 提到只导入特定对象可以节省内存。需要注意，`from math import sqrt` **并不意味着 Python 只加载了** `sqrt` **这一小部分模块**，它主要改变的是当前命名空间中名称的使用方式。

### **3. 模块导入时究竟发生了什么？**

这是一个容易忽略但很重要的问题。

假设：

```
# test_module.py

print("模块正在加载")

def hello():
    print("Hello")
```

另一个文件：

```
# main.py

import test_module

test_module.hello()
```

运行 `main.py` 时会发生什么？

输出：

```
模块正在加载
Hello
```

为什么没有主动调用 `print("模块正在加载")`，却执行了？

因为 Python 第一次导入一个模块时，会执行模块顶层的代码。

也就是说：

```
print("模块正在加载")
```

虽然不在函数里面，但它属于模块的顶层代码，导入模块时就会执行。

而函数内部的代码：

```
def hello():
    print("Hello")
```

只是定义了函数，并没有立即调用。

这一点非常重要：

- 模块顶层的普通语句：首次导入时执行。
    
- 函数定义：创建函数对象，不执行函数体。
    
- 函数调用：才会执行函数体。
    

通常，Python 会缓存已经导入的模块，避免在同一进程中每次 `import` 都重新执行整个模块的顶层代码。

因此，模块中不要随意放置会产生副作用的操作，例如一导入就删除文件、修改数据库等。

## **四、**`__name__`**：Python 模块中非常重要的特殊变量**

这是第六章最值得理解的知识点之一。

先看一个问题：

一个 `.py` 文件既可以被其他文件导入，也可以自己单独运行。

那么，Python 如何判断当前文件到底是被直接运行，还是被其他文件导入？

答案就是：

```
__name__
```

### **1.** `__name__` **的两种情况**

**情况一：直接运行 Python 文件**

例如：

```
python test.py
```

此时：

```
print(__name__)
```

输出：

```
__main__
```

**情况二：被其他模块导入**

假设：

```
# test.py
print(__name__)
```

另一个文件：

```
# main.py
import test
```

运行 `main.py`，输出：

```
test
```

也就是说：

|运行方式|`__name__` 的值|
|---|---|
|直接运行该文件|`"__main__"`|
|被其他模块导入|模块名，例如 `"test"`|

### **2. 为什么需要** `if __name__ == "__main__"`**？**

假设我们有一个模块：

```
# calculator.py

def add(a, b):
    return a + b


def main():
    print(add(10, 20))


if __name__ == "__main__":
    main()
```

另一个文件：

```
# test.py

import calculator

print(calculator.add(3, 5))
```

运行 `test.py`：

```
8
```

为什么没有输出 `30`？

因为 `calculator.py` 是被导入的，而不是被直接运行的。

因此：

```
if __name__ == "__main__":
    main()
```

这个条件不成立，`main()` 不会执行。

如果我们直接运行 `calculator.py`：

```
python calculator.py
```

此时条件成立，才会执行 `main()`，输出：

```
30
```

**运行逻辑**

Python 文件开始运行

判断 `__name__ == "__main__"`？

True

**直接运行**

执行 main() 中的代码

False

**被导入**

不执行该条件下的测试代码

这个机制在实际编程中非常常见。

你可以把它理解为：

**一个 Python 文件既可以作为独立程序运行，也可以作为工具模块供其他程序使用。**

PPT 第 11–13 页就是围绕这个机制展开的。

模块和包.pdf

### **3. 一个模块通常由什么组成？**

课件将模块划分为三部分：

1. 函数和类定义：提供可以重复使用的功能。
    
2. 顶层代码：模块加载时执行的代码。
    
3. 可执行语句：通常放在 `if __name__ == "__main__":` 中，负责测试或独立运行。
    

建议以后写自己的模块时，采用这样的结构：

```
# 1. 导入其他模块
import math

# 2. 定义函数
def calculate(x):
    return math.sqrt(x)

# 3. 定义主函数
def main():
    print(calculate(25))

# 4. 程序入口
if __name__ == "__main__":
    main()
```

这样既方便自己测试，也方便别人导入使用。

## **五、模块循环引用（Circular Import）**

PPT 第 9–10 页介绍了一个容易出错的问题。

假设：

`moduleA.py`：

```
from moduleB import B

class A:
    pass
```

`moduleB.py`：

```
from moduleA import A

class B:
    pass
```

这两个模块相互导入，就可能出现循环引用。

为什么？

假设 Python 首先导入 A：

1. Python 开始执行 A。
    
2. A 需要导入 B，于是开始执行 B。
    
3. B 又要从 A 中导入 A 类。
    
4. 但此时 A 还没有执行到 `class A`，模块还处于初始化过程中。
    
5. 因此可能找不到 A，产生导入错误。
    

注意，不是所有循环导入都必然失败，但这种结构容易产生初始化顺序问题。

### **如何解决？**

课件主要给出两种方法。

**方法一：重新设计模块结构。**

如果 A 和 B 都需要使用某些公共功能，可以把公共功能提取到 C 模块中。

例如：

```
project/
    main.py
    moduleA.py
    moduleB.py
    common.py
```

让 A 和 B 都导入 common，而不是相互导入。

**方法二：局部导入（Local Import）。**

把导入语句放在函数内部：

```
# moduleA.py

class A:
    def foo(self):
        from moduleB import B
        b = B()
```

这样只有在调用 `foo()` 时才进行导入，而不是在模块初始化阶段就导入。

不过，局部导入主要是缓解导入时机问题。对于复杂项目，优先考虑重新设计模块依赖关系。

## **六、包 Package**

现在我们已经知道：

一个 `.py` 文件可以作为模块。

那么，如果模块数量很多呢？

例如，机器学习项目可能包含分类、聚类和回归三类算法，每类又有很多算法实现。

这时候就需要包。

### **1. 什么是包？**

包（Package）可以理解为一个组织多个模块的目录。

例如：

```
ecommerce/
    __init__.py
    shopping_cart.py
    payments.py
    products.py
    customers.py
```

其中：

- `ecommerce` 是包。
    
- `shopping_cart.py` 是模块。
    
- `payments.py` 是模块。
    
- `products.py` 是模块。
    

PPT 第 14–16 页主要介绍了包的概念和创建方法。

模块和包.pdf

### **2.** `__init__.py` **是什么？**

在课件介绍的传统包结构中，包目录下需要有一个：

```
__init__.py
```

例如：

```
mypackage/
    __init__.py
    module1.py
    module2.py
```

这个文件可以是空的。

它的作用是标识和初始化包。

实际使用时，还可以在 `__init__.py` 中定义包的初始化代码，或者将常用函数暴露出来。

补充一个现代 Python 的区别：Python 3 也支持不包含 `__init__.py` 的命名空间包（Namespace Package）。不过课堂练习和普通项目中，按照 PPT 的结构创建 `__init__.py` 就可以。

### **3. 如何导入包中的模块？**

假设目录结构是：

```
project/
    main.py
    ecommerce/
        __init__.py
        shopping_cart.py
        payments.py
```

`shopping_cart.py`：

```
def add_to_cart(product):
    print(product, "已加入购物车")
```

在 `main.py` 中：

**方式一：导入模块**

```
from ecommerce import shopping_cart

shopping_cart.add_to_cart("苹果")
```

**方式二：直接导入函数**

```
from ecommerce.shopping_cart import add_to_cart

add_to_cart("苹果")
```

两种方式都可以。

它们与之前学习的模块导入方式是一样的，只不过现在多了包的层次。

### **4. 绝对导入和相对导入**

PPT 第 17 页介绍了这两种导入方式。

假设：

```
my_project/
    main.py
    mypackage/
        __init__.py
        submodule1.py
        submodule2.py
```

**绝对导入（Absolute Import）**

```
import mypackage.submodule1
```

直接从项目的包路径开始写，明确指出要导入哪个模块。

**相对导入（Relative Import）**

假设在 `submodule2.py` 中，希望导入同一包下的 `submodule1.py`：

```
from . import submodule1
```

这里的 `.` 表示当前包。

常见的相对导入符号：

|写法|含义|
|---|---|
|`.`|当前包|
|`..`|上一级包|
|`...`|上两级包|

例如：

```
from . import module1
from .. import module2
```

课件依据 PEP 8 推荐绝对导入，因为绝对导入通常更明确，尤其适合大型项目。

不过，在包内部组织模块时，相对导入也很常见。

有一个实际使用中的注意点：相对导入通常要求模块以包的一部分运行。如果直接运行某个子模块文件，可能出现 `attempted relative import with no known parent package`。此时通常从项目根目录使用 `python -m 包名.模块名` 运行。

### **5. 如何理解大型 Python 项目的结构？**

PPT 第 18–20 页给出了两个项目结构案例，其中一个是机器学习包。

例如：

```
machinelearning/
    __init__.py

    classifier/
        __init__.py
        knn.py
        decision_tree.py
        svm.py
        random_forest.py

    clustering/
        __init__.py
        k_means.py
        dbscan.py

    regression/
        __init__.py
        linear_regression.py
        ridge_regression.py
```

你可以发现，它并没有把所有算法写进一个文件。

而是：

- 分类算法放在 `classifier` 包中。
    
- 聚类算法放在 `clustering` 包中。
    
- 回归算法放在 `regression` 包中。
    

例如，要使用 KNN：

```
from machinelearning.classifier import knn
```

这种结构有什么好处？

第一，功能划分明确。

第二，可以让不同开发者负责不同模块。

第三，代码可以被其他程序重复使用。

第四，某个算法出现问题时，可以定位到对应模块，不必在一个巨大文件中寻找。

这也是你以后阅读 GitHub 上的机器学习项目时，经常看到大量文件夹和 `.py` 文件的原因。

# **第二部分：第七章 文件（File Operations）**

## **七、为什么需要文件？**

先想一个问题：

假设你写了一个 Python 程序：

```
scores = [90, 85, 95]
```

程序运行时，这些数据存储在计算机内存（Memory）中。

但如果程序关闭了，再次运行时，`scores` 这个变量就不存在了。

那么，如何让数据长期保存？

答案是：**将内存中的数据写入磁盘文件（File）中。**

例如：

```
程序运行
   ↓
内存中的数据
   ↓
写入文件
   ↓
磁盘长期保存
   ↓
下次运行时重新读取
   ↓
恢复数据
```

这就是文件操作的基本思想。

PPT 第 3–4 页首先将文件分成两种类型：文本文件（Text File）和二进制文件（Binary File）。

文件.pdf

### **1. 文本文件与二进制文件**

|对比|文本文件|二进制文件|
|---|---|---|
|存储形式|字符编码后的文本|字节（Bytes）|
|是否方便人类阅读|通常可以|通常不可以直接阅读|
|常见格式|`.txt`、`.csv`、`.json`|`.jpg`、`.png`、`.mp3`、`.bin`|
|Python 读取结果|`str`|`bytes`|

例如，一个文本文件中保存：

```
Hello Python
```

我们用文本编辑器就可以直接看到内容。

但一张 JPG 图片，内部存储的是大量二进制数据，并不是直接保存为人类可读的文字。

因此：

- 处理普通文字，通常使用文本模式。
    
- 处理图片、音频等原始数据，通常使用二进制模式。
    

这是后面所有文件操作的基础。

## **八、打开和关闭文件（PPT P5–P8）**

### **1. open()：打开文件**

Python 使用内置函数 `open()` 打开文件。

基本语法：

```
f = open(file, mode)
```

其中：

- `file`：文件路径和名称。
    
- `mode`：打开模式。
    
- `f`：返回的文件对象（File Object）。
    

例如：

```
f = open("data.txt", "r")
```

表示以只读模式打开当前工作目录中的 `data.txt`。

### **2. 文件打开模式（非常重要）**

这是本章最需要记忆的表格。

|模式|含义|文件不存在时|文件存在时|
|---|---|---|---|
|`r`|只读|报错|读取|
|`w`|写入|创建|清空原内容|
|`a`|追加|创建|在末尾追加|
|`rb`|二进制读取|报错|读取|
|`wb`|二进制写入|创建|清空原内容|
|`r+`|读写|报错|不清空原内容|
|`w+`|读写|创建|清空原内容|
|`a+`|读写|创建|写入时追加|

这里重点理解 `r`、`w`、`a`。

**（1）r：Read，只读模式**

```
f = open("data.txt", "r")
```

只能读取文件内容，不能写入。

如果文件不存在，会报错。

**（2）w：Write，写入模式**

```
f = open("data.txt", "w")
f.write("Hello Python")
f.close()
```

如果文件不存在，就创建文件。

如果文件已经存在，就会先清空原来的内容，再写入新内容。

这是一个很容易造成数据丢失的操作。

**（3）a：Append，追加模式**

```
f = open("data.txt", "a")
f.write("Hello Python")
f.close()
```

如果原来文件中有内容，不会删除，而是在末尾继续添加。

例如原文件：

```
I like Python.
```

执行后：

```
I like Python.Hello Python
```

注意，`write()` 不会自动换行。

如果想换行，需要：

```
f.write("\nHello Python")
```

### **3.** `+` **模式是什么意思？**

PPT 第 6 页介绍了 `+` 的作用。

它不是独立的打开模式，而是给原模式增加读取或写入能力。

例如：

- `r+`：可以读，也可以写，但文件必须存在。
    
- `w+`：可以读，也可以写，但原文件会被清空。
    
- `a+`：可以读，也可以写，写入时始终追加到末尾。
    

需要注意，`a+` 打开后，文件指针通常位于末尾。如果要读取已有内容，需要先执行：

```
f.seek(0)
```

### **4. 文件路径：绝对路径和相对路径**

PPT 第 7 页介绍了三种常用的路径写法。

**绝对路径（Absolute Path）**

例如 Windows：

```
f = open(r"D:\data\test.txt", "r")
```

提供文件的完整路径。

注意这里的 `r`：

```
r"D:\data\test.txt"
```

它表示原始字符串（Raw String），可以避免反斜杠 `\` 被当作特殊转义字符。

**相对路径（Relative Path）**

```
f = open("data/test.txt", "r")
```

表示相对于当前工作目录查找文件。

这里有一个特别重要的细节：

相对路径通常是相对于程序的当前工作目录（Current Working Directory），而不一定是 `.py` 文件所在目录。

可以用：

```
import os

print(os.getcwd())
```

查看当前工作目录。

这也是很多初学者明明文件存在，却出现 `FileNotFoundError` 的原因。

### **5. 为什么需要关闭文件？**

文件打开后，计算机需要分配相应的系统资源。

因此，操作完成后应该关闭文件：

```
f = open("data.txt", "r")

content = f.read()

f.close()
```

`close()` 的作用：

1. 释放文件相关资源。
    
2. 确保缓冲区中的数据得到正确处理。
    
3. 避免文件长期处于打开状态。
    

但是，这种手动关闭文件的方式有一个问题。

如果程序中间出现异常：

```
f = open("data.txt", "w")

# 如果这里出现异常
x = 1 / 0

f.close()
```

那么 `close()` 可能根本不会执行。

因此，Python 推荐使用 `with` 语句。

### **6. with：上下文管理器（Context Manager）**

这是本章最值得养成使用习惯的语法。

```
with open("data.txt", "r") as f:
    content = f.read()
    print(content)
```

它的意思是：

1. 打开文件。
    
2. 将文件对象赋值给 `f`。
    
3. 执行缩进代码块中的操作。
    
4. 代码块结束后自动关闭文件。
    

即使代码执行过程中出现异常，也会自动进行资源清理。

**with 语句的执行流程**

1. 调用 `open()`，打开文件
    
2. 将文件对象绑定到变量 `f`
    
3. 执行 with 代码块中的读写操作
    
4. 退出代码块，自动关闭文件
    

因此，后面所有文件操作，我都建议你优先使用：

```
with open(...) as f:
    ...
```

而不是手动调用 `close()`。

## **九、文本文件的读取与写入（PPT P9–P13）**

这是文件操作中最常用的部分。

### **1. 读取文件：read()、readline()、readlines()**

假设 `data.txt` 中有以下内容：

```
Hello Python
I like programming
Python is useful
```

Python 提供了三种常见的读取方法。

|方法|作用|返回值|
|---|---|---|
|`read()`|读取全部内容或指定数量的字符|字符串|
|`readline()`|读取一行|字符串|
|`readlines()`|读取所有行|字符串列表|

#### **（1）read()：读取全部内容**

```
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```

得到一个完整的字符串。

也可以指定读取数量：

```
f.read(5)
```

表示在文本模式下读取最多 5 个字符。

#### **（2）readline()：读取一行**

```
with open("data.txt", "r", encoding="utf-8") as f:
    line1 = f.readline()
    line2 = f.readline()

    print(line1)
    print(line2)
```

第一次调用读取第一行，第二次调用读取第二行。

#### **（3）readlines()：读取所有行**

```
with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

print(lines)
```

结果类似：

```
[
    "Hello Python\n",
    "I like programming\n",
    "Python is useful\n"
]
```

注意，每个字符串通常会保留原文件中的换行符 `\n`。

### **2. 为什么不推荐使用 readlines() 处理特别大的文件？**

这是 PPT 第 10–11 页强调的重点。

假设文件有 10GB。

如果使用：

```
lines = f.readlines()
```

Python 会把所有行一次性读取到内存中的列表里。

这会产生非常大的内存开销。

因此，对于大文件，推荐逐行读取：

```
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line)
```

这里的 `f` 本身支持迭代（Iteration）。

每次循环取得一行，而不需要先将整个文件变成一个列表。

你可以把三种方式理解为：

**read()**

一次性读取整个文件，得到一个字符串。

**readlines()**

一次性读取全部行，得到一个列表。

**for line in f**

逐行迭代，不需要同时保存全部行。

示意图：三种方法的内存使用方式，不代表实际内存占用比例。

注意，Python 文件对象本身具有缓冲机制，逐行遍历并不意味着每读一行就一定进行一次物理磁盘读取。

### **3. 写入文件：write() 和 writelines()**

#### **（1）write()**

```
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello Python\n")
    f.write("I like programming\n")
```

`write()` 用于写入字符串。

它不会自动添加换行符，因此需要自己添加 `\n`。

#### **（2）writelines()**

```
lines = [
    "Hello Python\n",
    "I like programming\n",
    "Python is useful\n"
]

with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

`writelines()` 可以一次写入一个字符串序列。

但是一定要记住：

**writelines() 不会自动添加换行符。**

如果列表中的字符串没有 `\n`，它们会直接连接在一起。

### **4. 文件指针 seek()（重点理解）**

PPT 第 13 页给出了一个很有代表性的例子。

```
with open("data.txt", "w+") as f:
    f.write("Hello Python")

    for line in f:
        print(line)
```

你可能会认为这段程序会打印 `Hello Python`。

但实际上不会。

为什么？

因为文件有一个当前操作位置（File Position），也可以理解为文件指针。

我们写入：

```
f.write("Hello Python")
```

之后，文件指针已经移动到文件末尾。

此时再读取，已经没有剩余内容了。

解决方法：

```
with open("data.txt", "w+") as f:
    f.write("Hello Python")

    f.seek(0)

    content = f.read()
    print(content)
```

`seek(0)` 将文件指针重新定位到文件开头。

**文件指针示意**

刚写入后

H

e

l

l

o

·

P

y

t

h

o

n

指针在末尾 ↑

执行 seek(0) 后

H

e

l

l

·

P

y

t

h

o

n

↑ 指针回到开头，可以重新读取

所以：

- `read()` 会从当前位置开始读取。
    
- `write()` 会从当前位置开始写入（追加模式除外）。
    
- `seek()` 可以改变当前位置。
    

这里的 `seek(0)` 是最常用的情况。

## **十、二进制文件操作（Binary File Operations）**

现在我们已经知道：

文本文件处理的是字符串 `str`。

那么，二进制文件处理的是什么？

答案是：字节序列 `bytes`。

### **1. 字符串 str 与字节 bytes**

这是 Python 中一个很重要的概念。

例如：

```
a = "Hello"
```

这里的 `a` 是字符串（String）。

而：

```
b = b"Hello"
```

这里的 `b` 是字节序列（Bytes）。

可以通过：

```
print(type(a))
print(type(b))
```

得到：

```
<class 'str'>
<class 'bytes'>
```

它们的区别：

|类型|表示什么|常见用途|
|---|---|---|
|`str`|文本字符|文本处理|
|`bytes`|字节数据|二进制文件、网络数据|

为什么要有这两个不同的类型？

因为计算机最终存储和传输的是字节，而我们编程时通常希望处理可读的文字。

因此需要在两者之间转换。

### **2. encode()：字符串转换为字节**

```
text = "Hello Python"

data = text.encode("utf-8")

print(data)
print(type(data))
```

输出：

```
b'Hello Python'
<class 'bytes'>
```

`encode()` 的作用就是编码。

\[ \text{str}\xrightarrow{\text{encode}}\text{bytes} \]

为什么需要指定 UTF-8？

因为不同字符编码方式会使用不同规则将字符转换成字节。

UTF-8 是目前非常常见的文本编码方式，尤其适合处理中文和英文混合文本。

### **3. decode()：字节转换为字符串**

反过来：

```
data = b"Hello Python"

text = data.decode("utf-8")

print(text)
# Hello Python
```

即：

\[ \text{bytes}\xrightarrow{\text{decode}}\text{str} \]

注意，编码与解码应该使用相互匹配的编码格式，否则可能产生乱码或解码错误。

### **4. 二进制文件的读取和写入**

假设我们希望将字符串保存为二进制文件：

```
text = "Hello Python"

# 字符串转换为字节
data = text.encode("utf-8")

# 写入二进制文件
with open("example.bin", "wb") as f:
    f.write(data)

# 读取二进制文件
with open("example.bin", "rb") as f:
    data_read = f.read()

# 字节转换为字符串
result = data_read.decode("utf-8")

print(result)
```

这里需要注意：

- `wb`：二进制写入。
    
- `rb`：二进制读取。
    

与文本模式不同，二进制模式下读取到的是 `bytes`，而不是 `str`。

例如，图片文件通常不能直接使用文本模式读取，因为它不是普通的文本字符序列。

## **十一、序列化与反序列化（Serialization）**

这是本章比较抽象，但在实际数据科学中非常重要的知识点。

### **1. 为什么需要序列化？**

假设我们有一个 Python 字典：

```
student = {
    "name": "Alice",
    "age": 20,
    "scores": [90, 95, 88]
}
```

这个字典目前存在于内存中。

如果程序关闭，变量就消失了。

我们希望把整个字典保存下来，下次运行程序时重新恢复。

一种简单的想法是，把它转换成文件可以保存的格式。

这就是序列化。

**序列化（Serialization）：将内存中的 Python 对象转换成适合存储或传输的形式。**

**反序列化（Deserialization）：将保存的数据重新恢复成 Python 对象。**

**Python 对象**

dict、list、tuple 等

**序列化 Serialization**

pickle / json

**文件中的数据**

保存到磁盘

读取文件后执行反序列化，即可恢复 Python 对象。

### **2. pickle 模块**

Python 提供了 `pickle` 模块，用于序列化和反序列化 Python 对象。

例如：

```
import pickle

student = {
    "name": "Alice",
    "age": 20,
    "scores": [90, 95, 88]
}

# 序列化：保存对象
with open("student.pkl", "wb") as f:
    pickle.dump(student, f)

# 反序列化：恢复对象
with open("student.pkl", "rb") as f:
    data = pickle.load(f)

print(data)
```

输出：

```
{
    'name': 'Alice',
    'age': 20,
    'scores': [90, 95, 88]
}
```

这里有四个非常重要的函数与模式：

|操作|函数|文件模式|
|---|---|---|
|序列化|`pickle.dump()`|`wb`|
|反序列化|`pickle.load()`|`rb`|

为什么 pickle 使用二进制模式？

因为它生成的是二进制形式的数据，而不是为了直接阅读设计的普通文本。

**注意：不要对来源不可信的 pickle 文件执行** `pickle.load()`**，因为恶意构造的 pickle 数据可能在反序列化时执行任意代码。**

### **3. json 模块**

除了 pickle，Python 还有一个非常重要的模块：`json`。

JSON 全称是 JavaScript Object Notation，是一种广泛使用的数据交换格式。

例如：

```
{
    "name": "Alice",
    "age": 20,
    "scores": [90, 95, 88]
}
```

你会发现它和 Python 字典的结构非常相似。

但是，JSON 是一种通用的数据交换格式，不是 Python 专属的。

这意味着其他语言，例如 Java、JavaScript、C++，也可以处理 JSON 数据。

这就是 JSON 在 Web 开发和数据传输中非常常见的原因。

### **4. pickle 与 json 的区别**

|对比|pickle|json|
|---|---|---|
|主要用途|Python 对象持久化|通用数据交换|
|保存形式|二进制|文本|
|可读性|通常较差|较好|
|跨语言支持|较弱|很强|
|文件模式|`wb`、`rb`|`w`、`r`|
|常见函数|`dump()`、`load()`|`dump()`、`load()`|

你可以这样记：

- 只想方便地保存和恢复 Python 对象：可以考虑 pickle。
    
- 希望数据能够被其他语言读取：通常使用 JSON。
    

还有一点：JSON 并不能原样保存所有 Python 类型。例如，Python 元组经过 JSON 序列化后通常会变成 JSON 数组，读取后对应 Python 列表，不会自动恢复成元组。

### **5. JSON 的实际读写案例**

假设有一个 `users.json` 文件：

```
[
    {
        "name": "Zhang San",
        "age": 20,
        "city": "Beijing"
    },
    {
        "name": "Li Si",
        "age": 21,
        "city": "Guangzhou"
    }
]
```

现在希望：

1. 读取用户信息。
    
2. 将所有用户的年龄增加 1。
    
3. 为用户添加新的兴趣爱好。
    
4. 保存到另一个 JSON 文件。
    

代码：

```
import json

# 读取 JSON 文件
with open("users.json", "r", encoding="utf-8") as f:
    users = json.load(f)

# 修改数据
for user in users:
    user["age"] += 1

    if "coding" not in user["hobbies"]:
        user["hobbies"].append("coding")

# 保存到新文件
with open("updated_users.json", "w", encoding="utf-8") as f:
    json.dump(users, f, ensure_ascii=False, indent=4)
```

这里重点理解两个函数：

**读取：**

```
users = json.load(f)
```

从 JSON 文件中读取数据，并转换成 Python 对象。

**写入：**

```
json.dump(users, f, indent=4)
```

将 Python 对象转换成 JSON 格式，写入文件。

其中：

- `indent=4`：控制缩进，让 JSON 文件更容易阅读。
    
- `ensure_ascii=False`：允许中文直接以中文形式写入，而不是转换成 `\uXXXX` 形式。

## **十二、os 模块：操作文件和目录**

前面我们主要学习的是文件内容的读写。

但还有一个问题：

如果我们想知道文件是否存在、删除文件、重命名文件，应该怎么办？

Python 提供了 `os` 和 `os.path` 模块。

### **1. os 模块**

首先：

```
import os
```

就可以使用 os 模块中的功能。

PPT 第 18 页给出了以下常用函数：

|函数|功能|
|---|---|
|`os.remove(path)`|删除文件|
|`os.rename(src, dst)`|重命名文件或目录|
|`os.chmod(path, mode)`|修改权限|
|`os.stat(path)`|获取文件状态信息|
|`os.listdir(path)`|获取目录下的文件和子目录名称|

例如：

```
import os

# 查看当前目录中的内容
print(os.listdir("."))

# 检查文件是否存在
if os.path.exists("data.txt"):
    print("文件存在")

# 重命名文件
if os.path.isfile("old.txt"):
    os.rename("old.txt", "new.txt")

# 删除文件
if os.path.isfile("test.txt"):
    os.remove("test.txt")
```

这里：

```
"."
```

表示当前工作目录。

### **2. os.path 模块**

`os.path` 主要负责路径的处理和判断。

|函数|功能|
|---|---|
|`os.path.exists(path)`|路径是否存在|
|`os.path.isabs(path)`|是否为绝对路径|
|`os.path.isdir(path)`|是否为目录|
|`os.path.isfile(path)`|是否为文件|
|`os.path.split(path)`|分离目录和文件名|
|`os.path.join(a, b)`|拼接路径|

例如：

```
import os

path = "D:/data/test.txt"

print(os.path.exists(path))
print(os.path.isabs(path))
print(os.path.isfile(path))

print(os.path.split(path))
```

其中最值得掌握的是：

```
os.path.join()
```

为什么？

假设我们有：

```
folder = "data"
filename = "test.txt"
```

不建议直接这样拼接：

```
path = folder + "/" + filename
```

因为不同操作系统的路径分隔符可能不同。

推荐：

```
path = os.path.join(folder, filename)
```

它会根据操作系统自动选择适合的路径分隔符。

### **3. 目录操作**

文件夹也可以通过 Python 管理。

PPT 第 21 页介绍了几个常见操作：

|函数|功能|
|---|---|
|`os.mkdir(path)`|创建目录|
|`os.rmdir(path)`|删除空目录|
|`os.listdir(path)`|查看目录内容|
|`os.getcwd()`|获取当前工作目录|
|`os.chdir(path)`|切换当前工作目录|

例如：

```
import os

# 查看当前工作目录
print(os.getcwd())

# 创建目录
if not os.path.exists("data"):
    os.mkdir("data")

# 切换当前工作目录
os.chdir("data")

print(os.getcwd())
```

注意：

`os.rmdir()` 只能删除空目录。

如果目录中还有文件，不能直接使用它删除整个目录。

### **4. os.walk()：递归遍历目录（重点）**

这是本章比较重要的一个函数。

假设有这样的文件夹：

```
data/
    train/
        train1.csv
        train2.csv
    test/
        test1.csv
    result.txt
```

如果想获取这个目录及其所有子目录中的文件，可以使用：

```
import os

for root, dirs, files in os.walk("data"):
    print("当前目录：", root)
    print("子目录：", dirs)
    print("文件：", files)
```

`os.walk()` 每次迭代返回三个内容：

\[ (\text{dirpath},\text{dirnames},\text{filenames}) \]

分别是：

- `root`：当前正在遍历的目录路径。
    
- `dirs`：当前目录下的子目录名称列表。
    
- `files`：当前目录下的文件名称列表。
    

如果想打印所有文件的完整路径：

```
import os

for root, dirs, files in os.walk("data"):
    for name in files:
        path = os.path.join(root, name)
        print(path)
```

例如：

```
data/train/train1.csv
data/train/train2.csv
data/test/test1.csv
data/result.txt
```

这在实际数据分析中非常有用。

例如，你有一个数据集目录，里面包含几十个子文件夹，每个子文件夹又有多个 CSV 文件，就可以使用 `os.walk()` 批量遍历。

## **十三、CSV 文件处理**

现在开始进入文件操作的实际应用。

你以后做数据分析时，会经常遇到 CSV 文件。

### **1. 什么是 CSV？**

CSV 全称是 Comma-Separated Values，即逗号分隔值。

例如：

```
name,age,score
Alice,20,90
Bob,21,85
Charlie,20,95
```

每一行表示一条记录，每个字段之间使用逗号分隔。

你可以把它理解成一个简单的二维表格：

|name|age|score|
|---|---|---|
|Alice|20|90|
|Bob|21|85|
|Charlie|20|95|

### **2. 使用 csv.reader() 读取文件**

Python 有一个内置的 `csv` 模块。

```
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)

    for row in reader:
        print(row)
```

输出：

```
['name', 'age', 'score']
['Alice', '20', '90']
['Bob', '21', '85']
['Charlie', '20', '95']
```

注意，这里的每一行都是一个列表。

例如：

```
['Alice', '20', '90']
```

其中的数据默认都是字符串。

如果需要进行数学计算，应该转换类型：

```
age = int(row[1])
score = float(row[2])
```

### **3. 为什么使用 newline=""？**

你可能会注意到：

```
open("students.csv", "r", newline="", encoding="utf-8")
```

这里多了一个 `newline=""`。

这是为了让 `csv` 模块自己正确处理换行，尤其可以避免 Windows 系统中读写 CSV 时出现多余空行的问题。

`encoding="utf-8"` 则用于指定文件编码，避免中文读取时出现编码错误。

### **4. 使用 csv.writer() 写入文件**

```
import csv

data = [
    ["name", "age", "score"],
    ["Alice", 20, 90],
    ["Bob", 21, 85],
    ["Charlie", 20, 95]
]

with open("output.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)

    writer.writerow(["name", "age", "score"])

    writer.writerows(data[1:])
```

两个重要方法：

|方法|作用|
|---|---|
|`writer.writerow()`|写入一行|
|`writer.writerows()`|写入多行|

与前面学过的 `write()` 和 `writelines()` 不同，`csv.writer()` 会负责按照 CSV 格式处理字段分隔和必要的引号。

例如，如果某个字段本身包含逗号，CSV 模块会正确处理，不需要自己手动拼接。

## **十四、把两章知识串起来：一个完整的数据处理流程**

现在我们已经学了：

- 模块：将程序拆分成多个文件。
    
- 包：将多个相关模块组织起来。
    
- 文件：读写磁盘数据。
    
- JSON：保存结构化数据。
    
- CSV：读取和保存表格数据。
    
- os：管理文件和目录。
    

这些知识可以组合成一个非常简单的学生信息管理项目。

假设项目结构如下：

```
student_project/
│
├── main.py
│
├── student.py
│
└── students.json
```

其中：

- `main.py`：程序入口。
    
- `student.py`：存放学生信息管理函数。
    
- `students.json`：保存学生数据。
    

### **1. student.py**

```
def add_student(students, name, score):
    student = {
        "name": name,
        "score": score
    }

    students.append(student)


def average_score(students):
    if not students:
        return 0

    total = sum(s["score"] for s in students)

    return total / len(students)
```

这个模块负责学生数据处理。

### **2. main.py**

```
import json
from student import add_student, average_score

# 读取数据
try:
    with open("students.json", "r", encoding="utf-8") as f:
        students = json.load(f)
except FileNotFoundError:
    students = []

# 添加学生
add_student(students, "Alice", 90)
add_student(students, "Bob", 85)

# 计算平均分
print("平均成绩：", average_score(students))

# 保存数据
with open("students.json", "w", encoding="utf-8") as f:
    json.dump(students, f, ensure_ascii=False, indent=4)
```

这里综合使用了：

|知识点|代码|
|---|---|
|模块导入|`from student import ...`|
|函数|`add_student()`|
|列表|`students`|
|字典|每个学生的信息|
|文件读取|`open()`、`json.load()`|
|文件写入|`json.dump()`|
|上下文管理器|`with`|
|异常处理|`try-except`|

这就是一个简单但完整的数据持久化程序。

它已经具备了一个基本的数据管理系统的核心流程：读取已有数据、修改数据、计算结果、保存数据。
