# 随机过程索引

随机过程把一族随时间或空间索引的随机变量作为整体研究。本目录当前已形成“条件化工具 -> 离散时间马尔可夫链 -> 长期行为、吸收与可逆性 -> MCMC/MDP/HMM -> 指数等待与泊松过程 -> 连续时间链与后续主题”的路线。

## 学习主线

1. 条件化工具：从 [[数统/随机过程/Ch03_条件概率与条件期望_中英讲解|Ch3 条件概率与条件期望（主线版）]] 建立条件分布、全期望、全方差、首步分析和随机和框架；需要更多推导与例题时对照 [[数统/随机过程/Ch03_条件概率与条件期望_中英讲解(1)|Ch3 条件概率与条件期望（展开版）]]。对应 [[00-Wiki/Concepts/条件分布|条件分布]] 与 [[00-Wiki/Concepts/条件期望|条件期望]]。
2. 建模对象：阅读 [[数统/随机过程/Stochastic_Processes_Lecture1_Bilingual_Notes#2. 从随机试验到随机过程|从随机试验到随机过程]]，区分索引集、状态空间、固定时刻的随机变量和固定样本点的样本路径。对应 [[00-Wiki/Concepts/随机过程|随机过程]]。
3. 离散时间马尔可夫链：先读 [[数统/随机过程/Ch04_4.1-4.3_马尔可夫链_中英讲解|Ch4.1—4.3 建模、多步转移与状态分类]]，再读 [[数统/随机过程/Ch04_4.4-4.5_长期比例极限概率与应用_中英讲解 (1)|Ch4.4—4.5 长期比例、极限概率与应用]]，区分平稳分布、长期比例和逐步极限。对应 [[00-Wiki/Concepts/马尔可夫链|马尔可夫链]] 与 [[00-Wiki/Concepts/平稳分布|平稳分布]]。
4. 暂态、分枝与可逆性：用 [[数统/随机过程/Ch04_4.6-4.8_暂态停留分枝过程与时间可逆性_中英讲解|Ch4.6—4.8]] 掌握暂态基本矩阵、吸收概率、分枝过程灭绝概率和细致平衡。
5. 马尔可夫链的三个扩展：用 [[数统/随机过程/Ch04_4.9-4.11_MCMC_MDP_HMM|Ch4.9—4.11：MCMC、MDP 与 HMM]] 区分“设计链来抽样”“加入动作做决策”和“由观测反推隐藏状态”，再用 [[数统/随机过程/Ch04_第四章总复习_优化版_教材符号统一|第四章总复习]] 把有限时刻、长期、首达、累计访问与三类扩展串起来。
6. 指数等待与泊松过程：从 [[数统/随机过程/Ch05_5.1-5.3_指数分布与泊松过程_逻辑梳理与解题方法|Ch5.1—5.3 指数分布与泊松过程]] 掌握无记忆性、指数竞争、次数—间隔—到达时刻三种视角以及叠加、分类和条件到达时刻。对应 [[00-Wiki/Concepts/泊松过程|泊松过程]]。
7. 连续时间马尔可夫链：掌握指数停留时间、嵌入链、生成矩阵、Kolmogorov 方程、平稳分布和出生—死亡过程。
8. 后续主题：按 [[数统/随机过程/学习路线|学习路线]] 进入更新、排队、布朗运动、模拟、耦合和基础鞅；当前只链接已被 Git 跟踪的路线与讲义。

## 阶段检查

| 阶段 | 重点 | 完成标准 |
| --- | --- | --- |
| 概率工具 | 条件分布、全期望、随机和 | 能选择条件变量并写出条件化计算 |
| 离散链 | 转移矩阵、状态分类、平稳分布 | 能判断常返/暂留、周期性并求长期比例 |
| 到达过程 | 泊松、更新、更新报酬 | 能在计数、间隔和到达时刻三种视角间转换 |
| 连续时间链 | 停留时间、嵌入链、生成矩阵 | 能由速率图写出生成矩阵并求平稳分布 |
| 综合应用 | MDP、排队、布朗运动 | 能把状态、时间、转移/到达机制和目标量写清 |

## 复习抓手

- 每题先明确时间集合、状态空间、随机机制和要求计算的对象，再选择递推、条件化或平稳分析。
- “马尔可夫”只表示给定当前状态后未来与更早历史条件独立，不表示相邻状态彼此独立。
- 泊松过程、更新过程和连续时间马尔可夫链都涉及随机时间，但假设、状态和目标量不同，要分别写清。
- 条件期望题先决定对什么条件化，再检查全期望公式中的第一步分解是否完整。
- 本轮复习顺序：Ch4.6—4.8 暂态、分枝与可逆性 -> Ch4.9—4.11 抽样、决策与隐藏状态 -> Ch4 总复习统一方法 -> Ch5.1—5.3 指数等待与泊松计数。
