# 高维数据分析索引

本目录以线性回归为入口，逐步连接统计建模、正则化、降维、谱方法、低秩结构和现代高维学习主题。课程路线以讲义和课件为主，Applied Linear Regression 作为回归基础的教材参照。

## 学习主线

1. 回归入口：[[数统/高维数据分析/Ch1_散点图与回归_中英对照讲义|Ch1 散点图与回归]]，先从散点图、条件均值和条件方差区分相关、回归与因果，再用残差图识别非线性、异方差和特殊点。
2. 简单线性回归：对照 [[数统/高维数据分析/Ch2_简单线性回归_中英对照讲义|Ch2 简单线性回归]] 与 [[数统/高维数据分析/lecture02.pdf|第二讲课件]]，掌握模型假设、OLS、残差、自由度、区间估计、检验、预测和 $R^2$。
3. 多元线性回归：对照 [[数统/高维数据分析/Ch3_多元线性回归_中英对照讲义|Ch3 多元线性回归]] 与 [[数统/高维数据分析/lecture03.pdf|第三讲课件]]，把标量模型改写为矩阵形式，理解调整后系数、满秩条件、协方差矩阵、中心化和附加变量图。
4. 后续高维主题：按 [[数统/高维数据分析/高维数据分析学习路线|高维数据分析学习路线]] 进入分类、PCA、谱方法、低秩矩阵、推荐系统、Transformer 与正则化等主题。

## 复习抓手

- 先从散点图判断关系和建模目标，再写模型、估计参数和检查残差。
- 简单回归按“模型与假设 -> OLS -> 抽样分布 -> 区间/检验 -> 预测 -> 诊断”复习；多元回归再补矩阵维度、满秩、调整后解释和协方差结构。
- 统计误差与残差、均值响应的置信区间与新观测的预测区间、边际关系与控制其他变量后的关系要成对区分。
- 进入高维主题前，先复习矩阵、投影、特征值和 SVD；不要把“变量多”直接等同于“模型有效”。
