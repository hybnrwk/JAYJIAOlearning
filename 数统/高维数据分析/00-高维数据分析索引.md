# 高维数据分析索引

本目录以线性回归为入口，逐步连接统计建模、正则化、降维、谱方法、低秩结构和现代高维学习主题。课程路线以讲义和课件为主，Applied Linear Regression 作为回归基础的教材参照。

## 学习主线

1. 回归入口：[[数统/高维数据分析/Ch1_散点图与回归_中英对照讲义|Ch1 散点图与回归]]，先区分响应变量、解释变量、散点图、相关与回归。
2. 简单线性回归：[[数统/高维数据分析/Ch2_简单线性回归_中英对照讲义|Ch2 简单线性回归]]，掌握 OLS、残差、区间估计、检验、预测和 $R^2$。
3. 多元线性回归：[[数统/高维数据分析/Ch3_多元线性回归_中英对照讲义|Ch3 多元线性回归]]，重点看矩阵表达、参数解释、共线性和模型诊断。
4. 后续高维主题：按 [[数统/高维数据分析/高维数据分析学习路线|高维数据分析学习路线]] 进入分类、PCA、谱方法、低秩矩阵、推荐系统、Transformer 与正则化等主题。

## 复习抓手

- 先从散点图判断关系和建模目标，再写模型、估计参数和检查残差。
- 简单回归与多元回归都要同时检查系数解释、区间/检验、预测和模型假设。
- 进入高维主题前，先复习矩阵、投影、特征值和 SVD；不要把“变量多”直接等同于“模型有效”。
